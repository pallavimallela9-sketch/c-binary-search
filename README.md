# Binary Search in C

## Description

This program searches for an element in a sorted array using the Binary Search algorithm.

Binary Search repeatedly divides the search range into two halves, making it faster than linear search for sorted data.

## Example

### Input

```text
10 20 30 40 50 60
Target: 40
```

### Output

```text
Element found at position 4
```

## Concepts Used

* Arrays
* Binary Search
* While Loop
* Conditional Statements
* Searching Algorithms
